# RepoPilot

RepoPilot is an AI-powered software engineering agent designed to assist
developers with repository-level software engineering tasks.

## Vision

RepoPilot can:

- understand GitHub issues
- analyze repository structure
- retrieve relevant code and documentation
- generate implementation plans
- propose code changes
- execute tests in an isolated environment
- debug failed changes
- perform AI-assisted code review
- create pull requests with human approval

## Architecture

The system is designed as a production-inspired AI engineering platform
with:

- FastAPI backend
- Next.js frontend
- LangGraph agent orchestration
- PostgreSQL + pgvector
- Redis
- Docker-based execution sandbox
- GitHub integration
- human-in-the-loop approval
- observability
- evaluation framework
